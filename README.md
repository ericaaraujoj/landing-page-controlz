# Control Z Estúdio

Control Z Estúdio é um site institucional desenvolvido com foco em apresentar serviços de forma clara e moderna. A proposta é transmitir uma identidade visual limpa, com navegação simples e uma experiência agradável tanto no desktop quanto no mobile.

O projeto foi pensado para destacar informações importantes como serviços oferecidos e formas de contato, utilizando uma estrutura organizada e interativa.

## 🛠️ Tecnologias utilizadas

- HTML5  
- CSS3
